# Website cá nhân — Nguyễn Viết Bảo

Website tĩnh giới thiệu bản thân, xây dựng bằng **HTML** và **CSS** , đáp ứng yêu cầu bài tập xây dựng website tĩnh.

## Cấu trúc thư mục

```
project/
├── index.html        # Trang chủ
├── about.html         # Giới thiệu (học vấn, kỹ năng, sở thích)
├── products.html       # Dự án đã thực hiện
├── contact.html        # Thông tin liên hệ
├── css/
│   └── style.css       # Toàn bộ định dạng giao diện
├── images/              # Hình minh họa 
└── README.md
```
